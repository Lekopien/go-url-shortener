A URL shortener in pure Go

A standard-library-only Go microservice: random base62 codes, custom aliases, click stats, expiring links, atomic persistence and graceful shutdown, in a tiny distroless image.

View sourceRun it locally

Highlights

Zero dependencies

net/http with Go 1.22 method routing; nothing else.

Concurrency-safe

RWMutex-guarded store, verified with 200 parallel redirects under the race detector.

Expiring links

Optional TTL per link; expired links answer 410 Gone. The clock is injectable for tests.

Safe input

Only absolute http(s) URLs, 8 KB body cap, validated aliases with reserved route names.

Crash-safe storage

JSON file written via temp file plus atomic rename.

Small image

Multi-stage build to a static binary on distroless, about 10 MB.

Run it

Run

git clone https://github.com/Lekopien/go-url-shortener
cd go-url-shortener
go run ./cmd/server        # http://localhost:8080
go test -race ./...

Use

curl -s localhost:8080/api/links -d '{"url":"https://lekopien.com","alias":"home"}'
curl -i localhost:8080/home     # 302 Found → https://lekopien.com
curl -s localhost:8080/api/links/home   # {"clicks": 1, ...}

Core of the redirect handler

func (s *Server) redirect(w http.ResponseWriter, r *http.Request) {
	l, err := s.Store.Resolve(r.PathValue("code"))
	switch {
	case errors.Is(err, ErrExpired):
		http.Error(w, "this link has expired", http.StatusGone)
	case err != nil:
		http.NotFound(w, r)
	default:
		http.Redirect(w, r, l.URL, http.StatusFound)
	}
}
